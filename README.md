# Medoro — ডাক্তার ও হাসপাতাল ডিরেক্টরি (ডিজাইন প্রোটোটাইপ)

এই ফোল্ডারে **Medoro**-র সম্পূর্ণ ডিজাইন প্রোটোটাইপ আছে — রাজশাহী-কেন্দ্রিক ডাক্তার/হাসপাতাল ডিরেক্টরি, যা পরবর্তীতে দেশব্যাপী স্কেল করার পরিকল্পনা নিয়ে বানানো।

⚠️ **এটা একটা প্রোডাকশন-রেডি ওয়েবসাইট না** — এটা React দিয়ে বানানো একটা **ভিজ্যুয়াল/ইন্টারঅ্যাকটিভ ডিজাইন প্রোটোটাইপ**, যেখানে সব ডেটা placeholder/mock (কাল্পনিক)। আসল ওয়েবসাইট বানাতে হলে নিচের "প্রোডাকশনে যাওয়ার পথ" অংশ পড়ুন।

---

## ১. এই জিপ ফাইলে যা আছে

```
medoro-site/
├── README.md                  ← এই ডকুমেন্ট
├── website-build-plan.md      ← Next.js + Supabase দিয়ে আসল সাইট বানানোর টেকনিক্যাল প্ল্যান (SQL স্কিমাসহ)
├── bundle.html                ← ব্রাউজারে সরাসরি খোলার মতো একটা স্ট্যান্ডঅ্যালোন ফাইল (ডাবল-ক্লিক করে দেখুন)
├── src/
│   ├── data.ts                 ← সব mock ডেটা এক জায়গায় (ডাক্তার, হাসপাতাল, ওষুধ ইত্যাদি)
│   ├── App.tsx                  ← মূল রাউটিং লজিক (কোন পেজ কখন দেখাবে)
│   ├── index.css                ← কালার/ফন্ট/গ্লোবাল স্টাইল টোকেন
│   └── components/               ← প্রতিটা পেজ ও রিইউজেবল উপাদান (নিচে তালিকা দেখুন)
├── tailwind.config.js          ← কালার প্যালেট, ফন্ট, অ্যানিমেশন কনফিগারেশন
├── package.json                 ← ব্যবহৃত লাইব্রেরির তালিকা
└── index.html                   ← এন্ট্রি পয়েন্ট
```

### সবচেয়ে সহজ উপায়ে দেখতে চাইলে
শুধু **`bundle.html`** ফাইলটা যেকোনো ব্রাউজারে ডাবল-ক্লিক করে খুলুন — ইন্টারনেট বা ইনস্টলেশন ছাড়াই পুরো সাইটটা কাজ করবে (সব পেজ ক্লিকযোগ্য)।

### কোড এডিট করে দেখতে চাইলে (ডেভেলপারদের জন্য)
```bash
cd medoro-site
npm install
npm run dev
```
তারপর ব্রাউজারে `http://localhost:5173` খুলুন।

## ২. ডিজাইন সিস্টেম

**কনসেপ্ট:** পুরনো দিনের ডাক্তারের প্রেসক্রিপশন-প্যাড ও ডায়েরির অনুভূতি — সাধারণ "cream + terracotta" বা "dark + neon" AI-জেনারেটেড লুক এড়িয়ে।

| উপাদান | মান | ব্যবহার |
|---|---|---|
| Primary (Pine) | `#123832` | হেডার, বাটন, লিংক |
| Accent (Gold) | `#C68A2E` | হাইলাইট, ব্যাজ, CTA |
| Alert (Brick) | `#A63D2F` | জরুরি সেবা, এরর স্টেট |
| Background (Paper) | `#F5F3EC` | মূল ব্যাকগ্রাউন্ড |
| Text (Ink) | `#16231C` | মূল টেক্সট |
| ফন্ট (হেডিং) | Fraunces | ক্যারেক্টারফুল সেরিফ |
| ফন্ট (বডি) | Work Sans | সাধারণ টেক্সট |
| ফন্ট (ডেটা) | IBM Plex Mono | ফি, ফোন নম্বর, টাইমিং |

**সিগনেচার এলিমেন্ট:** কার্ডের ওপরে perforated (ছিদ্রযুক্ত) বর্ডার — প্রেসক্রিপশন স্লিপ ছেঁড়ার অনুভূতি (`.perf-top` ক্লাস, `src/index.css`-এ ডিফাইন করা)।

⚠️ **নোট:** এই bundle.html-এ Google Fonts ইনলাইন করা যায়নি (bundling টুলের সীমাবদ্ধতার কারণে), তাই ব্রাউজারের ডিফল্ট ফন্ট দেখাচ্ছে। Next.js প্রজেক্টে `next/font/google` দিয়ে এই ফন্টগুলো সঠিকভাবে লোড হবে।

## ৩. পেজের সম্পূর্ণ তালিকা (মোট ৩১টি)

## ৪. বিজ্ঞাপন (Ad) সিস্টেম

`AdSlot.tsx` একটা রিইউজেবল কম্পোনেন্ট যা কোথায় বসানো হয়েছে:
- **গ্লোবাল** — Nav-এর নিচে (leaderboard) ও Footer-এর ওপরে (strip), তাই সব ৩১ পেজেই দেখা যায়
- **Doctors পেজ** — সাইডবারে + রেজাল্টের মাঝে ইন-ফিড কার্ড
- **DoctorProfile** — চেম্বার তথ্য ও রিভিউর মাঝখানে
- **Medicines** — ফার্মা ব্র্যান্ড স্পনসরশিপ স্লট
- **Hospitals** — গ্রিডের ওপরে ফিচার্ড লিস্টিং স্লট

আসল বিজ্ঞাপন বসাতে `AdSlot` কম্পোনেন্টের placeholder-এর জায়গায় Supabase থেকে fetch করা ছবি/লিংক বসাতে হবে (দেখুন `website-build-plan.md`-তে প্রস্তাবিত `ads` টেবিল স্কিমা)।

## ৫. প্রোডাকশনে যাওয়ার পথ (এই প্রোটোটাইপ থেকে আসল ওয়েবসাইট)

1. **`website-build-plan.md`** পড়ুন — এতে Next.js + Supabase দিয়ে প্রোডাকশন সাইট বানানোর সম্পূর্ণ SQL স্কিমা ও রোডম্যাপ আছে
2. `src/data.ts`-এর mock ডেটার জায়গায় Supabase query বসান
3. প্রতিটা `components/*.tsx` ফাইলের JSX/স্টাইল প্রায় হুবহু কপি করে Next.js পেজে বসানো যাবে — এই প্রোটোটাইপ থেকে ডিজাইন সিস্টেম ইতিমধ্যে রেডি
4. `tailwind.config.js`-এর কালার/ফন্ট টোকেন নতুন প্রজেক্টেও কপি করুন
5. `next/font/google` দিয়ে Fraunces, Work Sans, IBM Plex Mono লোড করুন
6. `AdSlot` কম্পোনেন্টে আসল বিজ্ঞাপন ডেটা যুক্ত করুন

## ৬. গুরুত্বপূর্ণ সীমাবদ্ধতা (মনে রাখবেন)

- সব ডেটা (ডাক্তারের নাম, ফোন নম্বর, ঠিকানা) **সম্পূর্ণ কাল্পনিক** — বাস্তব কোনো ব্যক্তি/প্রতিষ্ঠানের তথ্য না
- এখানে কোনো ব্যাকএন্ড/ডেটাবেস নেই — সব state শুধু ব্রাউজার মেমোরিতে থাকে, রিফ্রেশ দিলে হারিয়ে যায়
- ফর্মগুলো (Contact, JoinUs, Appointment) আসলে কোথাও ডেটা পাঠায় না — শুধু UI ডেমো
- বিজ্ঞাপন সংক্রান্ত সিদ্ধান্তের আগে BMDC-র নিয়মকানুন যাচাই করে নিন
